# Dependencies — Qualification Record (§24.1)

Fairing is Category B: every **trust-path** dependency is qualified here before it enters
`Cargo.lock`; the raised `fairing-askpass` crate (Category A) qualifies **every** direct
dependency. `cargo deny check` and `cargo audit` gate CI (§24.2); versions are pinned by
the committed lockfile and re-qualified at each G3 gate. The M0 and M1 figures are from
the lockfile of 2026-10-06 at M1 (102 packages; one duplicate, `linux-raw-sys` 0.9.4 via
`drm-sys` and 0.12.1 via `rustix`). At M2 the lockfile holds 260 packages, and `cargo deny`
warns about eleven duplicated crates: `arrayvec`, `block-buffer`, `cpufeatures`,
`crypto-common`, `digest`, `foldhash`, `hashbrown`, `heck`, `linux-raw-sys`, `miniz_oxide`
and `syn`. Security history is the RUSTSEC record at adoption; `cargo audit` on
2026-10-06 reports one ignored vulnerability and three informational advisories, recorded
under *Accepted advisories*.

Fairing ships three builds, and a crate's row says which it enters. The **initrd** build
(`--no-default-features`) is the trust path the initrd carries. The **splash** build
(`--no-default-features --features dbus`) runs after switch-root. The **full** build
(default features) adds the Nickel theme tool and runs only at build time and on demand.

Every product crate is `#![forbid(unsafe_code)]`; the "Unsafe posture" column records
where the unsafe that Fairing relies on actually lives.

## Adopted (M2 — theme tool: `fairing theme check|compile`)

None of this is on the trust path. Everything below enters only the full `fairing` build (cargo feature `theme-tool`, which enables `fairing-theme/compile`) and never either splash binary: `cargo tree -p fairing --no-default-features --features dbus` contains none of these 97 crate versions (the 68 in the first thirteen rows, which `cargo tree -e normal` reaches, and the 29 build-only ones in the last row), and `serde_json` is already adopted (M0). Nickel also pulls `regex` and `toml` into the full binary, together with `aho-corasick`, `regex-automata`, `regex-syntax`, `serde_spanned` and `toml_writer`.
